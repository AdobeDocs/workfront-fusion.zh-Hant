# Workfront Fusion發行活動： 2026年10月19日當週

本頁說明2026年10月19日當週在Adobe Workfront Fusion中所做的所有增強功能。

如需所有近期變更的清單，請參閱 [Adobe Workfront Fusion 發行活動](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)。

如需 Workfront Fusion 中近期的錯誤修正清單，請參閱 [Workfront 維護更新](https://experienceleague.adobe.com/zh-hant/docs/workfront-known-issues/releases/current-updates)頁面，並檢查任何標示為 Workfront Fusion 維護更新的更新。

## 新對應變數

對應面板中現在提供六個新的一般變數。 它們提供立即可用的案例和執行連結、API URL和所有權識別碼，因此您可以在對應欄位中包含這些值，而無需建立URL或硬式編碼團隊和組織ID。

* `scenarioUrl`： Fusion使用者介面中目前案例的連結。
* `executionUrl`： Fusion使用者介面中目前案例執行的連結。
* `scenarioApiUrl`：目前案例的Fusion API URL。
* `executionApiUrl`：目前執行詳細資訊的Fusion API URL。
* `teamId`：擁有目前情境的Fusion團隊識別碼。
* `organizationId`：與目前執行關聯的Fusion組織識別碼。

這些變數會擴充現有的`executionID`、`scenarioID`、`scenarioName`、`triggerTimestamp`和`operationsConsumed`變數。

如需詳細資訊，請參閱[一般函式](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md)。

## Fusion聯結器變更

Workfront Fusion聯結器現在支援更多動作，以便從情境中管理Fusion組織。

**新模組和動作**

* **複製記錄：**&#x200B;您現在可以複製連結。 使用相依性將來源掛接的相依性對應到目標，就像複製案例時一樣。
* **刪除記錄：**&#x200B;您現在可以刪除連線、資料存放區、資料存放區記錄、資料存放區記錄（大量）、資料結構、連結、索引鍵、案例或團隊。
* **列出記錄：**&#x200B;您現在可以列出DLQ、組織、團隊和使用者。
* **讀取記錄：**&#x200B;您現在可以讀取DLQ、目前的組織、團隊、使用者或授權的使用者。
* **取得記錄相依性：**&#x200B;您現在可以取得掛接的相依性。
* **取得記錄相依專案：**&#x200B;這個新模組會傳回資料存放區、掛接和案例的相依專案。 在刪除資源之前執行它，以檢查是否有任何依賴它的專案。

**其他更新**

* 標籤為多值的屬性篩選器現在接受使用`==`和`!=`運運算元的逗號分隔值。 目前只有使用者的`id`屬性支援此專案（例如，`id==123,456`）。
* 刪除掛接的佇列時，`except`引數會取代`excludeId`，而且只能在刪除所有專案時使用。 `id`引數現在接受逗號分隔清單。 刪除已經進行時，會傳回新的423回應。
* 取得案例或單一案例時，您現在可以使用`fields`引數來選擇傳回哪些欄位。

如需詳細資訊，請參閱[Workfront Fusion模組](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md)。

## Adobe Fusion MCP聯結器

新的Adobe Fusion MCP聯結器可讓您從案例中將自然語言提示傳送至Adobe Fusion MCP伺服器。 大型語言模型(LLM)會解譯您的請求，並呼叫完成請求所需的Fusion工具。

聯結器僅適用於託管的Adobe Fusion MCP端點。

如需詳細資訊，請參閱[Adobe Fusion MCP模組](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-fusion-mcp-modules.md)。
