# 檢視儲存體中的檔案版本記錄

如需儲存的概述，請參閱[儲存概述](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)。

Adobe儲存體中的檔案可以有多個版本。

## 檢視版本記錄

1. 在Workfront Fusion中，按一下左側導覽中的&#x200B;**儲存空間**。
1. 導覽至儲存庫和資料夾，其中包含您要檢視版本的檔案。
1. 選取檔案並按一下動作列中的&#x200B;**「版本」**。
**版本記錄**&#x200B;面板隨即開啟。
版本以最新為先列出，每個都顯示：
   * 版本號碼
   * 日期
   * **下載**&#x200B;按鈕

   目前（最新）版本標有&#x200B;**&quot;current&quot;**&#x200B;徽章

若要下載特定版本，請參閱從儲存體下載檔案一文中的[下載特定版本](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/download-files-from-storage.md#download-a-specific-version)。
